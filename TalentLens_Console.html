    Interview kit

    Questions built from the match, not a fixed list per job title. Depth questions on skills the resume evidences, probes on the gaps, difficulty set by the seniority the parser computed.

    AI interview simulation

    Answer in your own words. Each answer is scored against a stated rubric — structure, concrete detail, and whether it addresses the skill.

    ATS pipeline

    Stage machine with validated transitions and a full audit trail. Invalid moves are refused, not silently accepted.

    Pipeline funnel

    Stage counts and conversion, plus the event log a real webhook would replay.

    Recruitment pipeline

    How many candidates reached each ATS stage, with stage-to-stage conversion. Updates live as interviews are recorded.

    Voice screening

    Speak the answer; the browser transcribes it locally and the transcript is scored. 80% content, 20% delivery.

    Decision mix

    Every candidate × role pair the matcher has scored.

    End-to-end workflow

    Parse → match → interview → ATS → dashboard, timed on the loaded cohort.

    User satisfaction — Week-8 gate

    Target ≥85%. Measured from real responses with the standard System Usability Scale plus one CSAT question — never asserted. Evaluated once at least 8 people have answered.
